Merchants

Sell on PayPal? Try it on your own sandbox in 5 minutes.

When an AI agent buys something and it never arrives, Clearwake lets the buyer's agent and the seller's agent settle it inside PayPal within an hour, with proof, before it becomes a claim or a fee, and nothing is paid twice. Test money only. Nothing here touches a real account.

Three steps

  1. 1

    Get the code

    Clone the repository. Python only, no package to install for the first run.

    git clone --recurse-submodules https://github.com/Sriharsan/clearwake-paypal.git
cd clearwake-paypal
  2. 2

    Add your sandbox keys

    Create a sandbox app in the PayPal developer dashboard. Put its keys in a .env file. Git ignores that file. The acknowledgement line keeps it sandbox only.

    CLEARWAKE_SANDBOX_ACK=I_CONFIRM_SANDBOX_ONLY
PAYPAL_CLIENT_ID=
PAYPAL_CLIENT_SECRET=
PAYPAL_BASE_URL=https://api-m.sandbox.paypal.com
  3. 3

    Run it

    Open the console it prints. Your rules, said or typed once, become a signed policy. The two agents do the rest.

    python -m clearwake --port 8810

Already use PayPal's Agent Toolkit? Three lines.

Money moving tools get your limits, one request id per move, a read of PayPal's record before any retry, and a signed receipt. Read tools pass through unchanged.

pip install git+https://github.com/Sriharsan/clearwake-paypal
from clearwake import guard
tools = guard(paypal_toolkit_tools, policy="policy.yaml")
