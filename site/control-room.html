Policy files

    
The server reads the policy file, a model never does, and its hash is written into every receipt. A prompt, a buyer message or a model reply cannot change it. This page cannot edit it.

operations:
  refund:

    max_amount_minor: 500
    approval_above_minor: 200

    level: Execute within Limits
    max_amount_minor: 500
